# LadyTube 追加機能 (server/ext)

LadyTube のうち、派生元の WomanLive に足した機能の詳細です。v2.1.1 までは WomanLive 本体を改変しないアドオン
（WomanLive 拡張機能）として配っていたもので、その作りのまま `server/ext/` に入っています。導入方法はルートの README を見てください。

## 仕組み
- **読み込み**: 本体の `server/index.js` が express のアプリを作った直後に `require('./ext')(app)` で拡張を読み込みます。
  使用中ライブラリの DB は、本体の `server/db.js` が `server/ext/library.js` に聞いてから開きます。
- **検索**: 本体の一覧 `/api/videos` と件数 `/api/videos/count` は、`server/ext/routes/search.js` が返します
  (本体 `server/services/videoService.js` の `getVideos`/`getVideoCount` から呼ぶ)。項目検索・表示動画名の照合・
  拡張のソート・品番でまとめる表示は、ここで扱います。
- 追加データは `videos.db` の**新規テーブル**（`ext_*`）に保存。WomanLive から引き継いだテーブルの形は変えていません。
- **ライブラリ**を作ると、ライブラリごとの DB ファイル（`libraries\<ID>\videos.db`）を本体に開かせます（後述の「ライブラリ」）。

## 追加機能の一覧
記載順の概要です（各機能の詳細は以下の同名の節を参照）。
- **ライブラリ**: ライブラリの作成・取り込み・切り替え（動画・設定・メタデータをライブラリ単位で分ける）
- **動画情報**: カバー画像 / 拡張メタデータ / 関連動画アルゴリズム修正 / スクリーンショット関連（枚数表示・ソート・表示サイズ変更） / コマ送り / モバイルでの端末保存・アプリで開く / 動画ページの標準モード / 公開日と更新日の表示 / 各種ソート機能追加 / 動画タグ編集機能改善（グループ対応）/ DMM(FANZA) API連携
- **出演者**: 出演者一覧（関連動画数の表示・出演数ソート）/ 出演者タグ機能（グループ対応）/ 出演者タグ自動付与
- **一覧・ナビゲーション**: 検索結果のサムネイル切替（スクリーンショット／ジャケット）/ 検索結果のリスト表示（シリーズ・監督・ジャンル）/ 同じ品番の動画をまとめて表示 / 検索結果のサイドメニュー（絞り込み）/ 設定画面のサイドメニュー / メーカー一覧 / シリーズ一覧 / タグ一覧 / 公開カレンダー / ブックマーク / ナビゲーション統一（ヘッダー・メニュー・アイコン・配色）
- **操作・データ管理**: 一括操作 / 一覧ページの一括削除 / メタデータ置換 / メンテナンス（参照されていないデータの削除）/ バックアップ

## カバー画像
動画と同名の画像を指定フォルダから自動割り当てし、動画ページのスクリーンショット欄の先頭に表示（クリックで拡大）。
- 例: 動画 `AAA.mp4` に対し、フォルダ内の `AAA.jpg`（または .png/.webp 等）を自動表示。
- 設定画面「拡張機能：カバー画像」でフォルダを指定して保存。
- DMM 商品検索で取得したカバーは `ext_video_cover` テーブルに保存（フォルダ未設定でも表示可）。
- 両方あるときは**フォルダの画像を優先**します（自分で置いた画像を DMM のカバーより先に出す）。
- 実装: カードは `client/src/components/ExtWatchParts.jsx` の `CoverCard`(動画ページ `WatchPage.jsx` がスクリーンショットの欄の先頭に置く。拡大は拡張の `WL.lightbox`)。DMM の情報を反映したあとは `videometa.js` が `wlext-cover-refresh` を投げて取り直させます。

## 拡張メタデータ
評価(★)・表示名・品番・公開日・シリーズ名・メーカー・レーベル・作品監督・出演者・ジャンルを、
各動画ページ右下の「詳細情報を編集」ボタン（鉛筆）から編集し、動画ページに表示します。
- 右下の丸ボタンは上から ブックマークに追加 / 動画情報を検索 / タグを編集 / 詳細情報を編集 の順です。
- 品番・シリーズ・メーカー等はクリックで同条件を検索（後述の「検索トークン」を自動付与）。評価は検索・ソート可。
- 「表示動画名」を設定すると、一覧・検索でファイル名の代わりに表示されます。
- 検索画面右上の**「表示設定」に「動画表示名で表示する」**を追加しています（既定はON）。
  OFF にすると表示動画名を使わず、本家どおりファイル名で表示します。一覧・動画ページ・関連動画に効き、
  設定はブラウザに保存されます。並び替えの「表示名」は OFF でもそのまま使えます。
  ON のまま「拡張子を表示する」も ON にすると、表示動画名の後ろに元のファイルの拡張子を付けます。
- 実装: 一覧と動画ページの API が表示動画名を `ext_display_name` で返し、本体の画面が
  `client/src/utils/formatters.js` の `videoName` で名前を組み立てます。トグルは本体の表示設定(`UIOverlay.jsx`)にあります。
- 実装(動画ページ): 評価・ジャンル・出演者・品番などの表示と右下の丸ボタンは `client/src/components/ExtWatchMeta.jsx`(`WatchPage.jsx` が置く。本体のタグ編集ボタンの代わり)。詳細情報の読み込みと保存、編集・タグ編集・DMM 検索のダイアログは `videometa.js`。保存すると `videometa.js` が `wlext-meta-updated` で知らせ、動画ページが表示とタイトルを描き直します。

## 関連動画（メタデータ類似・事前計算）
動画ページの「関連動画」を、拡張メタデータの一致度で選出します。
- **本体の既定**: ファイルパスが前後する12件（実質「同フォルダ・ファイル名が近い動画」）のみ。
  メタデータを考慮していないため、これを類似度スコアリングに置き換えます。
- **採点**: シリーズ／出演者／メーカー／レーベル／監督／ジャンル／タグ／公開時期／評価の一致を計算し、
  上位12件を返します（**シリーズ最重視**が既定）。**重みは設定画面で調整可能**。
- **事前計算**: 結果は `ext_related` テーブルに保存。動画のメタを編集すると、その動画分は自動で再計算されます。設定画面「拡張機能：関連動画（重み付け）」の「全再計算」で全動画を一括計算も可能です。

## スクリーンショット関連（枚数表示・ソート・表示サイズ変更）
検索結果カードに、各動画のスクリーンショット枚数を表示し、枚数で並べ替えできます。各動画ページのスクリーンショット欄にスライダーを追加し、表示サイズを変更できます（画像そのもの・解像度は変更しません）。
- フォルダ名の右・ブックマークボタンの左に、単色カメラアイコンでスクリーンショット枚数を表示。
- 検索画面の並び替えに「スクショ数」を追加（押すたびに多い順と少ない順を切り替え）。
- 表示サイズは**80px〜640px**の範囲で変更（既定 160px。16:9 の縦横比を維持）。
- カバー画像（先頭のカバーカード）も同じサイズに追従します。
- 変更したサイズはブラウザに保存され、次回訪問時も引き継がれます。
- 実装: スライダーは `client/src/components/ExtWatchParts.jsx`(動画ページ `WatchPage.jsx` がスクリーンショットの欄の末尾に置く)。欄に付けた `--wlext-ss-w`/`--wlext-ss-h` を `womanlive-ext.css` がカードとカバーに当てます。

## コマ送り
動画を1コマずつ進める／戻せます。本家のホイール操作（5秒送り）はそのままです。
- **`.`** で1コマ送り、**`,`** で1コマ戻し。再生中に押すと一時停止してから動きます。
  文字入力中や拡張のダイアログを開いている間は反応しません。
- **プレイヤー上で Shift+ホイール**でも同じ操作。下方向で送り、上方向で戻しです。
- **スマホやタブレット**では、一時停止中のプレイヤーに半透明のボタンを重ねます。
  左端で1コマ戻し、中央で再生、右端で1コマ送りです。再生中とマウス操作の端末では表示しません。
  本家の横スワイプ（滑らせた距離で早送り・巻き戻しする操作）はそのまま使えます。
- 操作すると画面上部に、時刻とフレーム番号・フレームレート（例: `▶ 1:40.033 (2999F / 29.97fps)`）を
  1秒ほど表示します。
- フレームレートは ffprobe で取得し、動画ごとに1回だけ調べて以降は使い回します
  （本家は保持していないため。追加テーブルは作りません）。
- **変換再生（トランスコード）の動画はコマ送りできません**。セグメントを取り直す再生方式のためで、
  操作すると1回だけ通知します。ファイルをそのまま再生できる動画（mp4 など大半）が対象です。
- 実装: `client/src/components/ExtWatchParts.jsx` の `FrameStep`(プレイヤー `Player.jsx` が枠の最後に置く)、フレームレートは `server/ext/routes/frame.js`。

## モバイルでの「端末に保存」「アプリで開く」
本家の動画ページにある「フォルダーを開く」「アプリで再生」は、**サーバー機**のエクスプローラや
既定プレイヤーを開くもので、`localhost` で見ているときしか表示されません。手元の端末から見ている
ときに使えるよう、**タッチ端末(`(pointer: coarse)`)では次の2つ**を同じ位置に出します。
- **端末に保存**: ブラウザの標準ダウンロードで動画ファイルを保存します
  (`Content-Disposition: attachment`。日本語ファイル名は `filename*` で渡します)。
- **アプリで開く**: OS のアプリへ渡して再生します。Android は `intent:` でアプリ選択に渡し、
  開けるアプリが無ければ元のURLへ戻ります(`browser_fallback_url`)。iOS などは別タブで開くので、
  標準プレイヤーの共有メニューから他アプリへ渡せます。
- 配信は `GET /ext/api/video/:id/file`(`?dl=1` でダウンロード)。本家の `/api/stream/:id` は設定に
  よって変換したストリームを返すので、こちらは**常に元ファイル**をそのまま返します。外部プレイヤーが
  シークできるよう Range に対応しています。
- localhost をタッチ端末で見たときは、本家の2ボタンの代わりに出します。
- 実装: ボタンは `client/src/components/ExtWatchParts.jsx` の `MobileActions`(動画ページ `WatchPage.jsx` がタッチ端末のときだけ「コーデック情報」の箱の後ろに置く)、配信は `server/ext/routes/file.js`。

## 動画ページの標準モード
動画ページに、プレイヤーの右に情報欄を置く **標準モード** を追加します。今までの配置は **シアターモード** です。
- 切り替えはプレイヤー下の「プレイヤー設定」ボタンの右。説明は今のモードに応じて「シアターモードへ変更」/
  「標準モードへ変更」になります。**既定はシアターモード**で、選んだモードはブラウザに保存します。
- 標準モードは、ヘッダー・プレイヤー・右の情報欄・タイトルと再生回数の欄だけを、画面に収まる大きさで表示します
  (ページはスクロールしません)。情報欄はその中だけがスクロールします。
- 情報欄の項目は上の「＜」「＞」か項目名で切り替えます。
  - **サムネイル**: カバー画像を元の縦横比のまま欄の幅いっぱいに出し、その下にスクリーンショットを並べます(表示サイズ変更も可)。
  - **同じシリーズ**: 同じ品番のパートを先頭に、続けて同じシリーズの作品を公開日の古い順に並べます
    (品番ごとに1行・「N本」付き)。今の作品には印が付きます。見出しの「同じ品番」を押すとその品番で、
    シリーズ名を押すとそのシリーズで検索します。
  - **関連**: 関連動画の一覧。本家が次に自動再生する動画に「次に再生」と出します。
  - **情報**: タグ・詳細情報などシアターモードで下に出ている情報。
  - **イメージリスト**: イメージリストを開いている間だけ出て、自動でこの項目に切り替わります。
- 右下の丸ボタンは、標準モードの間は情報欄の下端に横一列で並べます。
- 幅 1000px 未満の画面と全画面表示では使わず、切り替えボタンも隠します。
- 実装: 切替・右欄の見出し・大きさは `client/src/components/ExtStandard.jsx`(動画ページ `WatchPage.jsx` が置く。切替ボタンはプレイヤーの
  `renderExtraControls`)。右欄の「同じシリーズ」「関連動画」の一覧は `server/ext/public/standard.js`
  (`WL.renderStdSeries`/`WL.renderStdRelated`。API `GET /ext/api/video/:id/siblings`・`GET /ext/api/videos/brief?ids=`)。
  右欄へ重ねる CSS は `womanlive-ext.css` の `body.wlext-std` の規則で、目印は `WatchPage.jsx` が付ける `data-wlext-std`。

## 公開日と更新日の表示
- 動画ページの「N 回再生」の横に、**公開日**と何年何ヶ月前か(例: `公開日 2016/12/22（9年10ヶ月前）`)を出します。
  1ヶ月未満は「今月」、未来の日付は「発売前」です。公開日が無いときは再生回数だけです。
- ここにあった本家の日時(ファイルの更新日時)は、詳細欄の「前回再生:」の下へ「更新日:」として移します。
- 実装: 動画ページ(`client/src/pages/WatchPage.jsx`)。公開日は動画の API が `ext_release_date` で返し、詳細情報を保存したときは
  `videometa.js` が `wlext-meta-updated` で知らせます。

## DMM(FANZA) 商品検索によるメタデータ自動設定
各動画ページの右下「🔍」ボタンから、品番で FANZA 商品情報を検索しメタデータへ自動設定します。
1. 設定画面「拡張機能：DMM(FANZA) 商品検索API」に API ID とアフィリエイトID を登録（各自の DMM アカウントで取得）。
2. 動画ページで🔍を押すと、品番(model_no)で検索。品番未設定ならエラー。
3. 結果が1件ならプレビュー → 「設定する」で反映。複数なら選択 → プレビュー → 反映。0件なら通知。
4. 反映内容: title→表示動画名 / date→公開日 / genre→ジャンル / series→シリーズ名 /
   maker→メーカー / actress→出演者(自動作成) / director→作品監督 / label→レーベル。
   (品番・評価は維持。カバー画像が未設定なら商品画像を取得して設定)
- **確認画面で項目ごとにチェックを外せます**。「現在の値 → 新しい値」を並べ、チェックを付けた項目だけを
  設定します(既定は全部オン)。カバー画像の取得も同じように選べます。
- **ジャンルだけは上書きせず、既存 + FANZA の和集合**にします(重複は除外・既存の並び順は保持)。
- **FANZA 側が空だった項目は、既存の値をそのまま残します**。確認画面には値のある項目だけを表示するので、
  そこに出ていない項目は変更しません(出演者情報を持たない商品を反映して、手で入れた出演者が消える問題への対応)。
- **レーベルが `----` のときは空として扱います**(FANZA はレーベルなしをこの名前で返すことがあります)。
- 商品の探し方は、売り場(動画→通販)ごとに次の順で試し、最初に見つかったものを使います。
  1. 品番をそのままキーワード検索 → 2. cid(`aarm00004` 形式)で厳密一致 → 3. cid 形の文字列をキーワード検索
  3 は content_id に接頭辞が付く作品のための逃げ道です(例: `TOTTE-283` の content_id は `1totte00283` で、
  1 と 2 のどちらでも 0 件になります)。
- **取得した商品は品番で照合し、一致するものだけを候補にします**。FANZA のキーワード検索は部分一致なので、
  そのままでは品番の前に別の英字が付いた作品まで拾ってしまいます(`AP-147` で `SLAP-147` が返るなど)。
  content_id 側の英字と数字を品番と突き合わせ、英字の直前が英字でないこと・数字がゼロ埋めの違いを除いて
  同じこと・その数字の後ろに数字が続かないこと(`CLUB-051` が `CLUB-513` に当たらない)を確かめます。

## 出演者一覧 (/performers)
ホーム画面の「出演者一覧」から開きます。
- **各画像の右上に関連動画数**をバッジで表示。
- ソート: 評価 / 出演数（関連動画数。評価の右） / ふりがな / 身長 / 体重 / バスト / カップ数 / ウェスト / ヒップ / 年齢 。**選択したソートはブラウザに保存され、ページを離れても次回表示時に復元されます**。
- 絞り込み: 出演者タグ / 「別名・氏名が重複する出演者のみ」(同一人物の重複登録を発見)。
- 「🗑 関連動画のない出演者を一括削除」: どの動画にも登録されていない出演者をまとめて削除可能。
  ライブラリが複数あるときは、どのライブラリの動画にも登録されていない出演者だけが対象です。
- ライブラリが複数あるときは「このライブラリに出演作がある出演者のみ」の絞り込みが増えます(既定で ON)。
 
## 出演者ページ
`/performer/:id`。氏名・ふりがな・誕生日・スリーサイズ・別名・出演者タグ等の編集、
画像アップロード＋正方形トリミング、関連動画・関連スクリーンショットを表示します。
- 動画ページの出演者の顔写真クリックで開きます。名前や🔎から同じ出演者を検索。
- **関連動画の件数**を「関連動画（N）」と見出しに表示します（N は出演している動画数）。
- **関連スクリーンショット**は関連動画と同じサムネイルサイズで表示します。見出し右の
  「最近」「ランダム」で切り替え可能。

## 出演者タグの自動付与
設定画面の「拡張機能：出演者タグ 自動付与ルール」で、条件に合う出演者へ自動でタグを付けます。
- ルール = 条件(フィールド・演算子・値) → 付与タグ。例: 身長 ≧ 170 → 高身長。
- フィールド: 身長/体重/バスト/ウェスト/ヒップ/カップ数/評価/年齢/血液型。
  年齢は誕生日から自動算出。カップ数や血液型は文字比較(D≧C など)。
- **出演者側にその項目が登録されていない場合、そのルールは不一致として扱います**(どの演算子でも付与しません)。
  未登録を空文字として比較していたため、カップ数の「≦ D」や「≠ F」が未登録の出演者全員に当たっていた問題への対応です。
  評価は未評価でも 0 が入るため、関連動画の平均評価と同じく未登録として扱います。
- 「適用」で全出演者へ一括付与(冪等)。
- 「同期」チェック時は、条件に合わない出演者から「ルールのタグ」を外します  (ルールに無いタグや手動タグはそのまま)。

## 検索結果のサムネイル切替（スクリーンショット／ジャケット）
検索画面上部の表示形式ボタン(グリッド/リスト等)の右に、サムネイルの切替ボタンを置きます。
- カメラ: 本家どおりスクリーンショットのサムネイル。画像: カバー画像(ジャケット)を表示。
- カバー画像が無い動画は、ジャケット表示でもスクリーンショットのままです。
- 選んだ状態はブラウザに保存します(端末ごと)。ボタンの見た目は本家の表示形式ボタンのクラスを借りています。
- 狭い画面で表示件数ボタンがはみ出さないよう、表示設定の行を折り返します。
- 実装: `server/ext/public/covermode.js`。

## 検索結果のリスト表示（シリーズ・監督・ジャンル）
検索結果をリスト表示にしたとき、拡張メタデータの一部をカードに並べます。グリッド表示・ポスター表示では出しません。
- **シリーズ名**: 評価の行の先頭(評価の左)。行幅の半分を超える名前は末尾を「…」にします(全体はマウスを乗せたときのツールチップに出ます)。
- **出演者と監督**: 評価の行の下に「出演者：A、B　監督：X」の形で並べます。どちらか片方だけでも出します。
- **ジャンル**: タグの行の先頭に、動画ページのジャンルと同じ見た目で並べ、タグとの間を「│」で区切ります。
  行に収まらないときはタグの側(末尾)から削って「…」を付け、マウスを乗せるとジャンルとタグを全部表示します。
- シリーズ名・監督・ジャンルを押すとその条件で検索します(`@series:"…"` / `@director:"…"` / `@genre:"…"`)。出演者を押すと出演者ページを開きます。
- 値は一覧 API (`/api/videos`) が一緒に返します(`routes/search.js` の `withCardFields`。メーカー・シリーズ・ジャンル・監督・出演者)。
- 実装: `client/src/components/ExtCardParts.jsx`(検索画面のカードだけに出す。サムネのメーカー名とフォルダ名、評価の行も同じファイル)。
  見た目は `womanlive-ext.css` のクラス(`.wlext-maker-ov` / `.wlext-folder-ov` / `.wlext-card-meta` ほか)。
  評価の行には、スクショ数(`screenshots.js`)とブックマーク(`bookmark.js`)が拡張側から入ります。

## 同じ品番の動画をまとめて表示
検索画面で、品番(拡張メタデータ)が同じ動画を1枚のカードにまとめます。パート分割された作品向けです。
- 切替ボタンは表示形式ボタンの並び(サムネイル切替の右)。**既定はまとめる表示**で、状態はブラウザに保存します。
- カードを押すと先頭のパート(ファイル名の自然順)を再生します。サムネイル左上の **「N本」** を押すと
  パートの一覧が開き、選んだ動画を再生します。カード名からは末尾の `_数字` を外して表示します。
- カードの並び順は、グループの中で今のソートの一番前に来るパートの位置です。条件に一部のパートだけが
  当たるときは、当たったパートだけでまとめます。
- 件数と絞り込み(サイドメニュー)の件数は、まとめた後の数で数えます。本家のカテゴリー欄の件数はファイル数のままです。
- 一括操作・リスト表示の「⋮」・グリッドの「⋮」のタグ付け外しは、**まとめた全パート**に効きます。
- プレビュー中に出る本家のミュートボタンは、「N本」の下へずらします。ポスター表示では「N本」を左下
  (シークバーとファイル名の帯の上)に置きます。
- 品番の無い動画はまとめません。
- 実装: まとめるのは `routes/search.js` の `groupedVideos`。トグルは検索画面(`SearchPage.jsx`)にあり、一覧と件数の要求に
  `group=1` を付けます。「N本」はカード(`VideoList.jsx`)が `ext_group_count` から出し、押したときの一覧は
  `server/ext/public/groupview.js` の `WL.openGroupMembers` です。カードの名前からパート番号を外すのは `core.js` が行います。

## 検索結果のサイドメニュー（絞り込み）
検索結果の左側に、今の結果をさらに絞り込むためのサイドメニューを出します。
- **画面左上の「絞り込み」ボタン**で開閉します。位置は固定で、スクロールしても動きません。
  既定は **PC=開く / モバイル=閉じる**(`(max-width: 900px), (pointer: coarse)` で判定)で、
  切り替えた状態はその端末に記憶します。狭い画面では一覧を押し出さず**重ねて表示**し、
  背景をタップすると閉じます。閉じている間はパネルを作らないので、候補の取得も走りません。
- 一番上が **評価** の範囲スライダー。0〜5 の点の両端をドラッグ(またはクリック)して範囲を決めます。
  動かしている間は数値表示だけ変わり、離した時点で検索し直します。検索条件は `rating` トークン2つ
  (`@rating:">=2" rating:"<=4"`)で、全域(0〜5)にすると `rating` を外します。下限0は未評価も含みます。
  (本家のソートボタン群にあった ★1〜★5 の絞り込みはここへ移しました)
- 続けて **ジャンル / タグ / メーカー / 出演者 / シリーズ** の順。各項目は**今の検索結果**に対する
  件数の多い順に並べ、右端に件数を出します。
- **上位5件を表示し、残りは「すべて表示（他 N 件）」で開閉**します(出演者は数百件になり得るので、
  開いたときに初めて描画します)。
- クリックでその条件を今の検索に足します。**適用中の項目はアクセント色**になり、もう一度押すと外れます。
  絞り込むたびに候補と件数も計算し直します。
- 出演者だけは検索が id 指定(`@performer:ID`)なので、表示は氏名・検索は id を使います。
- **検索結果画面では常に出ます**。キーワード検索(本家のタグバッジ・年月リンクからの遷移も含む)でも
  表示し、絞り込みを足しても**キーワードは消えません**。項目条件とキーワードは
  `@maker:"X" 温泉` のように1つの検索語として扱い、AND で絞り込みます。
  絞り込みを全部外すと、`@` の付かない元のキーワード検索に戻ります。
- **本家のフォルダ絞り込み(カテゴリー)と再生履歴ソートも候補の集計に効かせます**。一覧と同じ母集団を
  数えるため、`path` と `sort` も同じ条件で扱います。
- 一覧を右へ寄せる量は「パネルの右端 + 16px」になるよう実測して決めます(狭い画面では 22px で、パネルは一覧に重ねます)。
- 押すと検索画面の中で条件を変えます(ページ全体は読み直しません)。
- 実装: `client/src/components/ExtFacets.jsx`(検索画面 `SearchPage.jsx` が置く)、`routes/search.js` の `facets`、
  API `GET /ext/api/search/facets?q=...`。キーワードの条件組み立ては `routes/fullsearch.js` の
  `keywordWhere` を項目検索側と共用しています。

## メーカー一覧 (/makers)
ホーム画面と右上メニューの「メーカー一覧」から開きます。動画に設定されたメーカーを横長のリストで表示します。
- **メーカー画像**は 1:1。既定はメーカー名から生成した無地背景に名前を表示し、画像を登録すると差し替わります。
  右上に動画本数、右下の編集ボタンから画像を登録します。そのまま登録すると画像全体を中央に表示し、
  拡大すると正方形に切り取れます。GIF / APNG / WebP の**アニメーション画像は動いたまま**保存します
  (元の画像と表示範囲を保存し、表示するときに範囲を当てます)。
- 画像とメーカー名のクリックで、そのメーカーを検索(`@maker:"名前"`)。
- **平均評価**はそのメーカーの動画の評価の平均(評価0=未評価は計算から除外。全て未評価なら「評価なし」)。
- **キャッチコピー**は名前の下。クリックでその場で編集でき、Enter で保存・Esc で取り消しです。
- **TOP10タグ**はそのメーカーの動画に付いたタグを多い順に10個。クリックでメーカーとタグの AND 検索
  (`@maker:"名前" tag:"タグ"`)。
- **レーベル一覧**は開閉式で、`レーベル名(本数)` を本数の多い順に表示します。クリックでそのレーベルを検索。
  レーベル未設定の作品は **「レーベルなし」として本数によらず末尾**に置き、クリックすると
  そのメーカーのレーベル未設定の作品を検索します(`@maker:"名前" label:none`)。
- **FANZAリンク**は右下。リストページURLが登録されているときだけ表示し、新しいタブで開きます。
  **公式サイトURL**を登録すると、公式サイトへのリンクも並べます。
- ソート: メーカー名 / 動画本数 / 評価。**選択したソートはブラウザに保存され、ページを離れても次回表示時に復元されます**。
- 右端の「⋮」から**メーカー情報編集**(ふりがな・キャッチコピー・リストページURL・公式サイトURL)と、**メーカー情報取得**を実行できます。

### メーカー情報取得（DMM メーカー検索API）
「⋮」→「メーカー情報取得」で、FANZA から**読み仮名**と**リストページURL**を取得します。
API ID とアフィリエイトID は DMM 商品検索と同じ設定を使います。
- メーカー名が完全一致すれば確認画面へ。一致しなければ**候補の一覧**を出すので、選ぶか、
  名前を変えて検索し直してください。設定するかどうかは確認画面で決めます。
- **メーカー名そのものは変更しません**(動画側のメタデータなので、名前を変えるときはメタデータ置換を使います)。
- MakerSearch API はキーワード検索を持たず `floor_id` が必須のため、FANZA 動画のメーカーを全件取得して
  サーバー側に1時間キャッシュし、名前の突き合わせは拡張側で行います(初回だけ数秒かかります)。
- メーカー情報は `ext_makers` テーブルに保存し、バックアップの対象にも含めています。
  全ライブラリ共通で、既定のライブラリの DB に置きます(追加ライブラリにあった分は起動時にまとめます)。

## ブックマーク

## メタデータ置換
設定画面の本家「タグ置換」を「**メタデータ置換**」に差し替え、タグ以外のメタデータも一括置換できるようにします。
- 置換できる種別: **タグ / ジャンル / 出演者 / シリーズ名 / メーカー / レーベル**。
- **完全一致のみ**置換します(部分一致では置換しません)。置換前に確認ダイアログが出ます。
- タグは本家と同じ保存形式(前後を改行で囲む)を扱い、**本家のプリセットと拡張のグループレイアウト**も追従します
  (グループ見出しの `# 名前` は置換対象外)。
- 出演者は出演者マスタの名前を変更します。動画側は出演者IDで持っているのでそのまま追従します。
  置換後の名前が既に登録済みのときはエラーにします(統合は出演者ページで行ってください)。
- 本家のセクションは非表示にして同じ位置へ差し込みます。見た目は本家のクラス名を借りて再現します。
- 実装: `server/ext/routes/replace.js`、`public/settings.js`、
  API `GET /ext/api/metadata/replace-kinds`, `POST /ext/api/metadata/replace`。

## 一覧ページの一括削除
シリーズ一覧・出演者一覧・タグ一覧で、選んだ項目を全動画のメタデータから取り除きます。
操作と見た目は検索結果の一括操作(選択モード)と同じです。
- 右下のボタンで選択モードに入り、カードをクリックして選択します。「表示中をすべて選択」「選択をすべて解除」も同じ位置です。
- 1件以上選ぶと「⋮」が出て、そこから削除します。**削除する名前の一覧と件数を確認ダイアログで表示**します。
- 消えるのはメタデータの値だけで、**動画そのものは削除しません**。
  - シリーズ: 動画のシリーズ名を空にします。
  - タグ: 本家 `metadata.tags` から取り除き、**本家のプリセットと拡張のグループレイアウト**からも消します
    (グループ見出しの `# 名前` は対象外)。
  - 出演者: 動画側の紐づけを外し、出演者マスタからも削除します(0本の出演者が一覧に残らないようにするため)。
- 実装: `server/ext/public/listselect.js`、`routes/replace.js`、API `POST /ext/api/metadata/delete`。

## メンテナンス（参照されていないデータの削除）
動画ファイルが無くなったあとも残る拡張データを削除します。
- 本家のクリーンアップ(`DELETE /api/maintenance/metadata`)は `screenshots` と `metadata` しか消さないため、
  **そのままでは拡張側だけが hash をキーに残り続けます**。本家のクリーンアップに便乗して同じ条件で掃除します
  (本家は `res.json` をトランザクションの中で呼ぶので、同じトランザクションに乗り、後続の `VACUUM` で領域も回収されます)。
- 設定画面「拡張機能：メンテナンス（参照されていないデータ）」から、件数を確認して単独実行もできます。
- 対象: `ext_video_meta` / `ext_video_cover` / `ext_bookmarks` / `ext_related`。
  関連動画キャッシュは元動画が消えた行に加え、参照先が消えた行も対象です
  (`rel_hash` が NULL の「該当なし」印は元動画が生きていれば残します)。
- 出演者は「関連動画のない出演者を一括削除」が別にあるため対象外。タグサムネイルとブックマークフォルダは
  hash に紐づかないため対象外です。
- 実装: `server/ext/routes/maintenance.js`、`index.js` のフック、
  API `GET /ext/api/maintenance/orphans`, `POST /ext/api/maintenance/cleanup`。

## ライブラリ
動画・設定・メタデータを、ライブラリ単位で分けて切り替えます(例: AV とそれ以外)。
- **ライブラリ1つ = DB ファイル1つ**。既定のライブラリは今までの `videos.db` で、本体だけで起動したときもこれが開きます。
  追加したライブラリは `libraries\<ID>\videos.db`、一覧と使用中は `libraries\libraries.json` に保存します。
- **ライブラリごとに分かれるもの**: スキャン対象フォルダ・拡張子・除外パターン、動画一覧・サムネイル・スクリーンショット・タグ・
  再生履歴、拡張メタデータ(評価・品番・メーカー等)、ブックマーク、カバー画像、タグサムネイル、
  カバー画像フォルダ、関連動画の重み、ブラウザの検索履歴。
- **全ライブラリ共通のもの**: 出演者(プロフィール・画像)、メーカー情報(画像・キャッチコピー等)、公開設定、プリセットタグ(グループ配置を含む)、
  FANZA API ID、出演者タグのプリセットと自動付与ルール。出演者は既定のライブラリの DB に置き、
  追加ライブラリで動いている間は既定の DB をつないで読み書きします。
- **管理画面の「拡張機能：ライブラリ」**: 一覧(動画数・サイズ・最終利用)、作成(空 / 今のライブラリの設定を引き継ぐ /
  今のライブラリを丸ごと複製)、名前変更、切り替え、削除。設定を引き継ぐ作成では、スキャン対象フォルダとカバー画像フォルダは引き継ぎません。
- **ほかの videos.db の取り込み**: 指定した `videos.db`(フォルダ指定も可)をコピーしてライブラリにします。元のファイルは変更しません。
  本体の今の形式と表・列を照合し、WomanLive 以外の DB や形式の違う DB は拒否します。出演者は名前で突き合わせて
  共通の出演者へまとめ、共通側で空の項目は取り込み元の値で埋めます。
- **切り替え**: ヘッダーのロゴの右(ライブラリが2つ以上あるとき)か、管理画面から行います。サーバーが自動で再起動し、
  ブラウザはホームを開き直します。スキャン中は切り替えられません。再生中の動画は止まります。
  起動時は前回使っていたライブラリを開きます。
- **切り替えと削除は、サーバーを動かしている PC(localhost)からのみ**行えます。削除したライブラリのファイルは
  `libraries\_trash` へ移します。使用中と既定のライブラリは削除できません。動画ファイルには触れません。
- **切り替え前に開いていた画面**: 動画の id はライブラリごとに振られるため、切り替え前の画面からの書き込み(評価・タグ・再生位置の
  保存など)はサーバーが拒否し、画面はホームを読み直します。ほかの端末で開いている画面も、次の操作か画面に戻ったときに読み直します。
- **出演者の削除**: 共通なので、削除するとほかのライブラリの動画からも紐付けを外します。バックアップの復元も出演者は全ライブラリに反映されます。
- 仕組み: 本体の `server/db.js` が起動時に `library.bootPath()` で使用中ライブラリのファイルを開き、開いた直後に
  `library.opened(db)` で既定のライブラリを繋ぎます。切り替えではサーバーが終了コード 75 で終わり、`ladytube.bat` が
  起動し直します(コンソール画面はそのまま。2回目以降は `-browser` を外すのでタブは増えません)。`ladytube.bat` 以外から
  起動したとき(bat が渡す `LADYTUBE_RESTART=1` が無いとき)は自動で再起動せず、次の起動から切り替わります。
- 実装: `server/ext/library.js`、`server/ext/routes/library.js`、`server/ext/public/library.js`(と `api.js` の書き込みガード)。

## 設定画面のサイドメニュー
設定画面(本家の表記は「管理」)の左側に、設定項目の一覧を出します。
- 検索結果の絞り込みメニューと同じ流儀で、**画面左上の「設定項目」ボタン**で開閉します。
  既定は PC=開く / モバイル=閉じるで、切り替えた状態はその端末に記憶します。
  狭い画面では本文に重ねて表示し、項目を選ぶと閉じます。
- 項目をクリックすると画面上のその位置へ移動します(固定ヘッダーに隠れないよう手前で止めます)。
- 一覧は DOM から拾うので、個人用モジュールが足したセクションも自動で並びます。
  拡張側の項目は右端に **Ex** を付けます(判定は見出しではなくクラス。「メタデータ置換」は本家の
  体裁を借りていて見出しに「拡張機能：」が付かないため)。
- 画面の並びも次の順に揃えます。意味の近いものを隣に置くためで、一覧の順と画面の順が食い違って
  ジャンプ先が上下に飛ぶのも防げます。
  ライブラリ / スキャン / カバー画像 / 関連動画（重み付け） / 出演者タグ 自動付与ルール / メタデータ置換 /
  メンテナンス / メンテナンス（参照されていないデータ） / ネットワーク / DMM(FANZA) 商品検索API /
  バックアップ（追加機能データ） / (以降は個人用モジュールの項目)
- 実装: `server/ext/public/settingsnav.js`。

## 本家 ver.260914 への対応
本家の更新で変わった点に合わせています。
- **検索結果の件数**: 一覧(`/api/videos`)が件数を返さなくなり、`/api/videos/count` で別に取る作りに
  変わりました。LadyTube では、本体の一覧と件数はどちらも `routes/search.js` の `videos`/`count` が返すので、
  同じ条件で数えます(`@maker:"X"` も一覧と件数がそろう)。
- **フォルダ絞り込み(カテゴリー)**: `path` パラメータを拡張の検索でも解釈します。`path=root` は「すべて」。
  絞り込みを足しても `path` は保ったままです。
- **フォルダーツリーの廃止**: `/folder-tree` が無くなったので、メニューの項目を「カテゴリー」
  (`/search?path=root`)に差し替えました。
- **再生履歴ソート**: 本家に合わせ、未再生(`last_played_at` が NULL)を除きます。
- **ロゴの置換**: ロゴが `<a><span>WomanLive</span>…</a>` の形になったため、リンク直下のテキストだけを
  見ていた処理を、中の末端要素まで探す形にしました。
