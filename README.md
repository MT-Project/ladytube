動画管理ソフト **LadyTube** です。**WomanLive（woman projects）の派生版**で、WomanLive 本体に、
非公式アドオン「WomanLive 拡張機能」（v2.1.1まで）として配布していた機能を統合したものです。
※WomanLive を別に入れる必要はありません。

## 主な機能
WomanLive から引き継いだ基本機能:
- 指定フォルダの動画をスキャンして一覧化
- ブラウザでの再生（ブラウザで再生できない形式は変換し再生）、再生位置・再生回数・再生履歴の記録
- タグ付け、キーワード検索、フォルダ（カテゴリー）での絞り込み
- 同じネットワークのスマホやタブレットからのアクセス

LadyTube にて追加される機能:
- 動画管理機能の改善
  - ライブラリ機能：動画・設定・メタデータをライブラリ単位で分けて管理を可能に、出演者などは共通としています
  - 動画削除機能：親端末のみ動画を検索結果画面等から削除可能に、削除した動画はゴミ箱へ入ります
  - ファイル名の変更：親端末のみ動画ページや検索結果からファイル名を変更可能に、ルール（`{品番} {タイトル}` など）での一括変更や動画情報の取得時の変更も
  - データベースの自動バックアップ：起動時にDB情報を自動バックアップ（一日おき）
  - ブックマーク機能：動画をブックマーク可能に、ブックマークフォルダ毎にお気に入りの動画をまとめられます

- メタデータの拡張：評価・動画の表示名・品番・公開日・シリーズ・メーカー・レーベル・監督・出演者・ジャンル・作品紹介を設定可
  - 関連動画アルゴリズム改善：関連動画をメタデータの類似度で選定（重み調整可）
  - メタデータの一括置換：拡張メタデータ（ジャンル・出演者・シリーズ名・メーカー・レーベル）についても一括置換可能に
  - 特定タグ等の一括削除：一覧ページから特定のタグなどを選んで削除可能に
  - 品番の自動設定：スキャン時にファイル名から品番を設定（`ABC-123.mp4` など）
  - DMM(FANZA)API：APIによるメタデータ自動設定を可能に、スキャンで増えた動画は自動で取得（APIは各自で取得してください）

- 一覧ページ機能：メタデータ単位の一覧ページを新設
  - 出演者一覧／ページ：登録されている出演者を一覧で表示、出演者個別のプロフィールページ（公式サイトや SNS などの関連URL も）も
  - メーカー一覧：登録されているメーカーのロゴ画像・キャッチコピー・TOP10タグ・レーベル・FANZAリンクを掲載
  - シリーズ一覧：登録されているシリーズを一覧で表示
  - タグ一覧：登録されているタグを一覧で表示
  - カレンダー機能：更新日もしくは公開日で、年・月・日を選んで対象の動画を抽出

- 動画検索機能の改善：ソートやフィルター等の機能を追加
  - カバー画像の設定：指定フォルダから動画名と一致するものを自動で設定
  - サムネイル切替：動画サムネイルについて、スクリーンショットとカバー画像で切替
  - サイドメニュー：評価・再生時間・再生状況・タグ・ジャンル・メーカー・出演者・シリーズで絞り込みが可能
  - 同じ品番をまとめて表示：検索結果でパート分割された同じ品番の動画を1枚のカードにまとめて表示
  - 検索条件の保存：ホームおよび右上メニューから呼び出し、ホームのカスタマイズにも利用可能

- 動画再生機能の改善：
  - 再生モードの追加：標準モード（プレイヤーの右に情報欄を設置したスタイル）と既存のシアターモードを切り替え可能に
  - 動画情報の表示整理：タイトルの下に再生回数・公開日・評価を1行で表示、詳細は作品情報とファイル情報に分けて折りたたみ可能に
  - コマ送り機能：「.」「,」キーやShift+ホイール、スマホ/タブレットでは一時停止中のボタンでコマ送りを可能に
  - スクリーンショット場面への移動：「Shift+←」、「Shift+→」でスクリーンショットを撮った場面へ移動可能に
  - 次パートの自動再生：再生完了から5秒後に次の動画を自動再生、設定でON/OFF可能
  - ピクチャーインピクチャー：小窓で再生可能に
  - モバイル特有機能：動画の端末保存・他アプリでの再生を可能に

- その他
  - ホーム画面のカスタマイズ：ホーム画面に表示される要素をカスタマイズ可能に
  - LadyTube の終了：右上のメニューから終了可能に（サーバーを動かしている PC のみ）

追加した機能の詳細は `server/ext/README.md` を参照してください。

## 動作要件
- Windows（起動に bat ファイルを使います）
- 初回のセットアップ時にインターネット接続（Node.js と FFmpeg を公式の配布元からダウンロードします。Node.js（20.19 以降・22.12 以降・23〜25）と FFmpeg がインストール済みなら、それを使います）
- DMM 商品検索とカバー画像の取得時のみ、外部通信を使用

## 導入方法
1. [Release](https://github.com/MT-Project/ladytube/releases) から最新の **`LadyTube_X.X.X.zip`**（X.X.X はバージョン）をダウンロードして解凍
2. 中の **`LadyTube` フォルダ**を、書き込める場所（デスクトップやドキュメントなど）に置く
3. **`setup.bat`** を実行。Node.js と FFmpeg をダウンロードし、必要な部品を入れてから起動します
4. 2回目からは **`ladytube.bat`** で起動します

最初の画面の案内に従い、管理画面で動画のあるフォルダを指定してスキャンしてください。
終了するときは、右上のメニューの「LadyTube を終了」を押すか、コンソール画面を閉じます。

- Node.js 20.19 以降・22.12 以降・23〜25 がインストール済みなら、`setup.bat` は Node.js をダウンロードせずにそれを使います。FFmpeg も、`ffmpeg` と `ffprobe` が動いて libx264 と libwebp に対応していれば、それを使います。
- インストール済みの Node.js で動かしているときに、Node.js の大きな版を上げる（例: 24 から 26）と起動しなくなります。そのときは `setup.bat` をもう一度実行してください。

## WomanLive ＋ 拡張機能（v2.x）からの移行
WomanLive の `videos.db` と `libraries` フォルダは、そのまま LadyTube で使えます。

1. WomanLive を終了する（コンソール画面を閉じる）。動かしたままコピーすると、最後の書き込みが `videos.db` に入らないことがあります
2. 念のため、WomanLive のフォルダの `videos.db`（`videos.db-wal`・`videos.db-shm` があれば一緒に）と `libraries` フォルダを、別の場所にコピーしておく
3. 上の「導入方法」の 1〜2 で `LadyTube` フォルダを置く
4. **`setup.bat` を実行する前に**、WomanLive のフォルダの `videos.db`（`-wal`・`-shm` があれば一緒に）と `libraries` フォルダを `LadyTube` フォルダへコピーする。
   先に `setup.bat` を実行すると空のデータベースができて起動するので、その場合は LadyTube を終了し、できた `videos.db`・`videos.db-wal`・`videos.db-shm` を消してからコピーしてください
5. `setup.bat` を実行する。WomanLive の `.sys` フォルダを `LadyTube` フォルダへコピーしておくと、Node.js と FFmpeg のダウンロードを省けます（そのときも、残りの部品を入れるために `setup.bat` は一度実行します）
6. 起動したら、動画の数・評価・ライブラリの切り替えを確かめる

- ブラウザに残っている表示の設定（並び順・まとめ表示・サイドメニューの開閉など）は、開くアドレス（`http://localhost:19190`）が同じなので引き継がれます。
- WomanLive と LadyTube は同じポートを使うので、同時には起動できません。
- 元に戻すときは、WomanLive のフォルダで今までどおり `womanlive-ext.bat` から起動します。LadyTube はデータベースの形を変えていないので、そのまま戻れます。LadyTube で行った変更は LadyTube 側の `videos.db` にだけ入っているので、引き継ぐときは逆向きにコピーしてください。

## バージョンアップ
1. LadyTube を終了する（右上のメニューの「LadyTube を終了」か、コンソール画面を閉じる）
2. 新しい `LadyTube_X.X.X.zip` を解凍し、中の `LadyTube` フォルダの中身を、今の `LadyTube` フォルダへ上書きコピーする。
   `videos.db` と、`libraries`、`backups`、`.sys` の各フォルダは zip に入っていないので、そのまま残ります
3. `setup.bat` を実行する。Node.js と FFmpeg は今あるもの（`.sys` か、インストール済みのもの）を使い、部品を入れ直してから起動します

## アンインストール
`LadyTube` フォルダごと削除します。動画ファイルは削除されません。
データ（`videos.db`・`libraries` フォルダ・`backups` フォルダ）を残したいときは、先に別の場所へコピーしてください。

## データ・バックアップ
データは `LadyTube` フォルダの `videos.db` に保存されます。ライブラリを作った場合、追加したライブラリは
`libraries` フォルダにライブラリごとの `videos.db` として保存されます（既定のライブラリは `videos.db` です）。
管理画面の「バックアップ」から、追加した機能のデータ（メタデータ・出演者・画像・ブックマーク・設定）を
JSON で書き出し／復元できます。書き出しと復元は、サーバーを動かしている PC からだけ行えます。

### 自動バックアップ
起動したとき、前のバックアップから1日以上たっていれば、データベースを丸ごと `backups` フォルダに写します。
既定のライブラリは `backups\default`、追加したライブラリは `libraries` の中と同じ名前のフォルダに入り、
それぞれ新しい5つまで残します。ファイル名は `videos-日付-時刻.db` です。

戻すときは、LadyTube を終了してから、戻したいファイルを `videos.db`（追加したライブラリは
`libraries\<フォルダ名>\videos.db`）へ上書きコピーします。同じ場所に `videos.db-wal`・`videos.db-shm` があれば消してください。

## 更新履歴
### v3.13.0 (2026-11-22)
- **検索結果の絞り込みに再生時間を足しました**: サイドメニューの評価の下にあるスライダーで、再生時間の範囲を選びます。目盛りは 0、15、30、45、60、90、120、180、240分で、右端の240は上限なしです。下限を0にすると、長さのわからない動画も入ります。検索欄に書くときは `@duration:">=30" duration:"<=60"`（分）です。
- **動画ページのタイトルの下を1行にしました**: 再生回数と公開日を左に、評価を右端に並べます。公開日は「3年7ヶ月前」の形だけを出し、マウスを載せると年月日が出ます。フォルダ名（カテゴリー）は下のファイル情報へ移しました。
- **動画ページの詳細を「作品情報」と「ファイル情報」の2つの欄に分けました**: 作品情報は公開日、品番、シリーズ名、メーカー、レーベル、作品監督です。ファイル情報は場所、動画ファイル名、カテゴリー、長さ、サイズ、前回再生、更新日、登録日です。見出しを押すと欄を折りたたみ、閉じた欄はその端末で覚えます。標準モードでも同じです。
- **作品紹介を入れられるようにしました**: 「詳細情報を編集」の「作品紹介」に書くと、動画ページのジャンルの下に出ます。最初は2行だけで、押すと全文を開きます。改行と、太字やリンクなど一部のタグが使えます。それ以外のタグとスクリプトは出しません。標準モードでは、右の情報欄ではなくタイトルの下に出します。動画情報の確認画面は、取得元が紹介文を返したときだけ「作品紹介」の行を出します（FANZA の商品検索 API は紹介文を返さないので、FANZA からは入りません）。
- **出演者に関連URLを登録できるようにしました**: 出演者ページの評価の下にある「＋関連URL」（登録したあとは鉛筆）から、公式サイトや X、Instagram などの URL を入れます。入力欄は「URL を追加」で増やせます。登録した URL は種類に合ったアイコンで並び、押すと新しいタブで開きます。使えるのは http と https の URL だけです。
- **動画情報の確認画面に「すべて」の行を足しました**: 項目のチェックをまとめて付けたり外したりできます。ファイル名の行は入りません。
- **標準モードでは、動画の下の欄だけがスクロールするようにしました**: 作品紹介を開いて長くなっても、動画は画面の上に出たままです。

これまでの更新履歴は `CHANGELOG.md` を見てください。
